Privacidad.

Qué información usa el plugin, dónde permanece y cómo funciona este sitio.

omabinds funciona localmente. No tiene cuentas, analítica, publicidad ni un servicio remoto propio. Tus mappings, comandos y rutas no se envían al mantenedor.

01Alcance

Esta política cubre el plugin omabinds sin modificar y el sitio web del proyecto. No cubre versiones modificadas ni las prácticas de Omarchy, Hyprland, GitHub, las aplicaciones que abras o cualquier otro software de tu sistema.

02Información que usa el plugin

Para mostrar y administrar atajos, omabinds procesa en tu equipo los bindings Lua efectivos de Hyprland, nombres de acciones, archivos de aplicaciones XDG, comandos, rutas e iconos. También consulta la configuración de Hyprland para detectar conflictos y verificar cambios.

Las aplicaciones seleccionadas se abren mediante gio launch y los comandos configurados se ejecutan cuando activas su atajo. Esas aplicaciones o comandos pueden tener actividad de red propia, independiente de omabinds.

03Almacenamiento local

El estado gestionado se guarda en ~/.config/omabinds/state.lua. Los archivos state.previous.lua, transaction.json y pending.lua permiten restaurar una operación interrumpida. Las exportaciones se guardan solo cuando eliges una ubicación.

Estos archivos pueden contener nombres, comandos y rutas personales. No están cifrados ni se cargan automáticamente a ningún servicio. Al desinstalar sin --purge --yes, el estado y los backups se conservan.

04Este sitio web

Este es un sitio estático para GitHub Pages. No incluye analítica, publicidad, formularios, fuentes remotas ni contenido de terceros incrustado. No puede leer la configuración del plugin.

Si cambias la paleta, el sitio guarda omabinds-theme en el almacenamiento local del navegador. El botón Copiar escribe únicamente el comando visible cuando lo pulsas. El sitio funciona cuando JavaScript o el almacenamiento no están disponibles.

GitHub puede procesar información técnica de la solicitud al alojar el sitio bajo su propia política. Los enlaces externos están sujetos a las prácticas de sus servicios.

05Contacto y cambios

El mantenedor no recibe datos automáticos del plugin. Si compartes un informe en el repositorio, revisa que no contenga comandos privados, rutas personales o archivos de recuperación.

Los cambios de esta política aparecerán aquí con una nueva fecha de vigencia.
