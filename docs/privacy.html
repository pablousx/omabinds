Privacidad.

Qué información usa el plugin, dónde permanece y cómo funciona este sitio.

Vigente desde el 22 de septiembre de 2026 · Mantenido por pablousx

En esta página 01 / Resumen 02 / El plugin 03 / Archivos locales 04 / Este sitio 05 / Contacto y cambios

omabinds funciona localmente. No tiene cuentas, analítica, publicidad ni un servicio remoto propio. Tus mappings, comandos y rutas no se envían al mantenedor.

01 / Alcance

Esta política cubre el plugin omabinds sin modificar y el sitio web del proyecto. No cubre versiones modificadas ni las prácticas de Omarchy, Hyprland, GitHub, las aplicaciones que abras o cualquier otro software de tu sistema.

02 / Información que usa el plugin

Para mostrar y administrar atajos, omabinds procesa en tu equipo los bindings Lua efectivos de Hyprland, nombres de acciones, archivos de aplicaciones XDG, comandos, rutas e iconos. También consulta la configuración de Hyprland para detectar conflictos y verificar los cambios.

Las aplicaciones seleccionadas se abren mediante gio launch y los comandos que configures se ejecutan cuando activas su atajo. Esas aplicaciones o comandos pueden tener su propia actividad de red, independiente de omabinds.

03 / Almacenamiento local

El estado gestionado se guarda en ~/.config/omabinds/state.lua. Los archivos state.previous.lua, transaction.json y pending.lua permiten restaurar una operación interrumpida. Las exportaciones se guardan solo cuando eliges una ubicación.

Estos archivos pueden contener nombres, comandos y rutas personales. No están cifrados y no se cargan automáticamente a ningún servicio. Al desinstalar sin --purge --yes, el estado y los backups se conservan para una reinstalación.

04 / Este sitio web

Este es un sitio estático para GitHub Pages. No incluye analítica, publicidad, formularios, fuentes remotas ni contenido de terceros incrustado. El sitio no puede leer la configuración del plugin.

Si cambias el tema, se guarda la preferencia omabinds-theme en el almacenamiento local del navegador. El botón Copiar escribe únicamente el comando de instalación visible cuando lo pulsas. Ambas funciones son opcionales y el sitio funciona sin JavaScript.

Cuando GitHub Pages aloja el sitio, GitHub puede procesar información técnica de la solicitud según su propia política. Los enlaces externos están sujetos a las prácticas de sus respectivos servicios.

05 / Contacto y cambios

El mantenedor no recibe datos automáticos del plugin. Si compartes un informe en el repositorio, revisa primero que no contenga comandos privados, rutas personales o archivos de recuperación.

Los cambios de esta política aparecerán aquí con una nueva fecha de vigencia.
