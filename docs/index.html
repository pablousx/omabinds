03 / INSTALACIÓN

Añádelo desde
tu terminal.

Ejecuta el comando como tu usuario normal dentro de una sesión Hyprland activa. Omarchy pedirá confirmación.

~ / terminal
omarchy plugin add https://github.com/pablousx/omabinds.git --enable

Primer inicio: abre omabinds desde el launcher o el icono de teclado. Si falta la integración local, el panel mostrará Open setup terminal; ejecútalo y después pulsa Refresh status.

04 / REQUISITOS

Hecho para tu
sesión Omarchy.

No instala paquetes Python, no requiere privilegios de administrador y no usa un daemon propio.

  • 01Omarchy 4.0.4
  • 02Hyprland 0.56.2 con configuración Lua
  • 03Quickshell y una sesión Hyprland activa
  • 04Python 3, libxkbcommon y gio
